# Boards

Keep a list or a few shared notes beside a thread. Open **Board** in the header, choose **Add a note**, or select a card’s text to edit it. Use its menu to move it to another section, set its expiry date, or remove it. **Open in Files** opens the same Markdown document.

This private development build uses the host’s existing thread file storage. It requires the API 0 thread control and Markdown projection slots. The card editor and file projection are adapted from Loam under the GNU Affero General Public License, version 3. See LICENSE at the repository root.
