The chat board is `Boards/Chat board.md` in the vault — one Markdown board for the owner’s quick thoughts and ideas across Chats. Keep it short, and add an item there only when the owner asks or it is plainly their kind of quick capture. Format items as a plain bullet `- text <!-- YourName · new · until YYYY-MM-DD -->` (use `- [ ] text` only for a task to tick off), using `until` only for a time-bound item and leaving `new` until the owner marks the item seen.
